# 🚀 Яндекс Вебмастер Lite & Android APK

Легковесный, быстрый и современный клиент **Яндекс Вебмастера** (webmaster.yandex.ru) для веб-браузера и мобильных устройств на базе Android.

---

## 🌟 Основные возможности приложения:

1. **Сводка и статус сайта (Dashboard & Deployments):**
   - Виджет с точным статусом развертывания: *«Ваш сайт доступен по адресу https://zapahstarosti.ru / Последнее развертывание @ooppanki2021 17 минут назад»*.
   - Показатель **ИКС (Индекс качества сайта)** с динамикой за 30 дней.
   - Интерактивный график 30-дневной аналитики (Клики, Показы, CTR, Средняя позиция в поиске, ИКС).
   - Быстрый переключатель между всеми добавленными сайтами.

2. **Поисковые запросы и трафик (Search Queries):**
   - Полная аналитика по поисковым фразам в Яндексе: Показы, Клики, CTR, средняя позиция, динамика (+/-).
   - Фильтры по датам (7 дней, 30 дней, 90 дней, 1 год), устройствам (Десктоп, Смартфоны) и поиск по фразе.
   - Экспорт в CSV.

3. **Индексирование и страницы в поиске:**
   - Список страниц в поиске с HTTP-кодами ответов и датами сканирования.
   - Исключенные страницы с точными причинами (HTTP 404, robots.txt, Canonical, noindex).

4. **⚡ Переобход страниц (Fast Reindex):**
   - Мгновенная отправка новых и обновленных URL в приоритетную очередь обхода роботом Яндекса.
   - Трекинг дневной квоты (20/20) и статуса («В очереди», «Робот обошел»).

5. **Проверка и тестер robots.txt:**
   - Встроенный редактор и анализатор файла `robots.txt`.
   - Интерактивный URL-тестер для `User-agent: Yandex`: мгновенная проверка `Allow` / `Disallow` с подсветкой сработавшего правила.

6. **Управление файлами Sitemap (Карты сайта):**
   - Добавление и валидация файлов `sitemap.xml`.
   - Мониторинг количества URL в карте, статуса обработки и ошибок.

7. **Диагностика сайта и безопасность:**
   - Автоматический аудит 15+ SEO-факторов (HTTPS, SSL, скорость ответа, мобильная адаптивность).
   - Проверка отсутствия поисковых фильтров и санкций Яндекса (Баден-Баден, Мимикрия, АГС).

8. **Инструменты Вебмастера:**
   - Проверка ответа сервера и HTTP-заголовков.
   - Удаление страниц из поисковой выдачи.
   - Инструмент подтверждения прав (HTML-файл, Мета-тег, DNS TXT-запись).

## 📱 Установка на Android (APK):

1. Скачайте установочный файл **`yandex-webmaster.apk`** (~150 КБ).
2. Откройте файл на телефоне и подтвердите установку («Установить из этого источника»).
3. Приложение работает полностью автономно, имеет темную тему и мгновенный отклик.

---

## 💻 Локальный запуск Web-версии:

```bash
cd yandex-webmaster-lite
npm install
npm run dev
```

Сервер запустится по адресу: `http://localhost:5173`.

---

## 🛠️ Сборка APK из исходников:

```bash
chmod +x build-yandex.sh
./build-yandex.sh
```

Скрипт автоматически скомпилирует Web-бандл, упакует ресурсы, сгенерирует DEX-байткод и создаст подписанный `yandex-webmaster.apk` и архив `yandex-webmaster-apk.zip`.
