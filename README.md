# 📱 Webmaster & GitHub Mobile Suite (Web + Android APKs)

Полный комплект двух современных автономных веб-сервисов и мобильных Android-приложений:
1. 🔴 **Яндекс Вебмастер Lite** (Мониторинг сайтов, ИКС, Fast Reindex, robots.txt, Sitemap, API v4)
2. 🐙 **GitHub Lite** (Управление репозиториями, коммитами, кодом, ветками и профилями)

---

## 📦 Готовые к установке файлы Android (APK):

| Приложение | Файл установки | Описание |
| :--- | :--- | :--- |
| 🔴 **Яндекс Вебмастер Lite** | [**`yandex-webmaster.apk`**](./yandex-webmaster.apk) | Официальный клиент Яндекс Вебмастера со всеми инструментами и связью с API |
| 🐙 **GitHub Lite** | [**`github-lite.apk`**](./github-lite.apk) | Полнофункциональный мобильный клиент GitHub для Android |

## 🗜️ Полные архивы проектов:

* 🗜️ [**`yandex-webmaster-apk.zip`**](./yandex-webmaster-apk.zip) — Исходный код, веб-бандл, Android SDK скрипты для Яндекс Вебмастера *(32 МБ)*.
* 🗜️ [**`github-apk.zip`**](./github-apk.zip) — Исходный код, веб-бандл, Android SDK скрипты для GitHub Lite *(30 МБ)*.

## 🌟 1. Возможности «Яндекс Вебмастер Lite»:

* **📊 Главный Dashboard:** статус сайта `https://zapahstarosti.ru`, ИКС, график кликов и показов за 30 дней.
* **🔍 Поисковые запросы:** статистика по ключевым словам из выдачи Яндекса, фильтры и экспорт в CSV.
* **⚡ Переобход страниц (Fast Reindex):** мгновенная отправка новых и обновленных URL в приоритетную очередь робота Яндекса через официальный API v4.
* **🤖 Тестер `robots.txt`:** интерактивный URL-валидатор правил `User-agent: Yandex` с подсветкой сработавших директив `Allow`/`Disallow`.
* **🗺️ Карты сайта (`sitemap.xml`):** мониторинг статуса обработки и количества страниц.
* **🛡️ Диагностика сайта:** аудит SSL/HTTPS, скорости ответа сервера, мобильной адаптивности и отсутствия поисковых санкций (Баден-Баден, Мимикрия).
* **🛠️ Инструменты SEO:** проверка HTTP-заголовков и времени отклика сервера, удаление URL из поиска, подтверждение прав.

---

## 🌟 2. Возможности «GitHub Lite»:

* **📂 Проводник кода:** просмотр файлов, подсветка синтаксиса для 20+ языков, Markdown-рендерер.
* **📝 Коммиты и диффы:** история коммитов с цветной визуализацией изменений (+/-).
* **🌿 Ветки и теги:** просмотр структуры веток и релизов.
* **🔍 Поиск и тренды:** поиск по репозиториям, авторам и популярным проектам на GitHub.
* **💾 Оффлайн-кэш:** мгновенная работа без зависаний даже при слабом интернет-соединении.

## 🛠️ Сборка APK из исходников:

Для сборки любого приложения запустите соответствующий скрипт:

```bash
# Сборка Яндекс Вебмастера
chmod +x build-yandex.sh
./build-yandex.sh

# Сборка GitHub Lite
chmod +x build-github.sh
./build-github.sh
```

---

## 💻 Локальный запуск Web-версий:

```bash
# Яндекс Вебмастер Lite
cd yandex-webmaster-lite
npm install
npm run dev

# GitHub Lite
cd github-lite
npm install
npm run dev
```
