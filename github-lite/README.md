# 🚀 GitHub Lite — Лайтовое приложение для GitHub

**GitHub Lite** — это быстрый, интуитивный и минималистичный веб-клиент для [GitHub.com](https://github.com), созданный специально для удобного поиска и изучения проектов без лишней сложности разработки (без мерджей, веток, конфликтов, терминалов и PR-диффов).

---

## 🌟 Основные возможности

### 1. 🔥 В тренде & Обзор (Trending & Explore)
- **Популярные проекты**: Самые интересные и трендовые репозитории по периодам (за сутки, за неделю, за месяц, за все время).
- **Фильтр по стеку**: Быстрый выбор языков (JavaScript, TypeScript, Python, Rust, Go) и тем (🤖 AI & Нейросети, 🛠️ DevTools, 📱 Mobile, ⚡ Web).
- **Быстрый просмотр (Quick README)**: Модальное окно с мгновенным просмотром файла README без перехода со страницы.

### 2. 🔍 Умный поиск (Smart Search)
- **Поиск репозиториев**: Мгновенный поиск библиотек, фреймворков и инструментов с фильтрацией по языку и сортировкой (по звёздам, форкам, недавним обновлениям).
- **Поиск разработчиков**: Просмотр профилей пользователей и организаций.
- **Быстрые подсказки**: Теги в 1 клик (`#deepseek`, `#telegram-bot`, `#ai-agent`, `#fastapi` и др.).

### 3. 📖 Карточка репозитория (Repository Details)
- **Чистый README**: Форматированный Markdown со стилями кода, таблицами и бейджами.
- **🏷️ Релизы и прямые загрузки (Releases)**: Просмотр версий, описания изменений и прямые ссылки на скачивание архивов `.zip`, `.tar.gz` и исполняемых файлов/установщиков.
- **💬 Вопросы и обсуждения (Issues)**: Просмотр открытых и закрытых вопросов, меток (labels) и комментариев участников.
- **👥 О проекте и авторах**: Список ключевых контрибьюторов, лицензия, размер репозитория и дата создания.
- **Копирование команд**: Быстрое копирование `git clone` или веб-ссылки в 1 клик.

### 4. 👤 Профиль разработчика (User Profile)
- Аватар, имя, био, контакты (веб-сайт, Twitter/X, компания, локация).
- Счётчики подписчиков, подписок и публичных репозиториев.
- Список всех репозиториев автора с поиском и сортировкой.

### 5. ⭐ Персональные закладки (My Bookmarks)
- Сохранение любимых репозиториев локально в браузере (без необходимости логина).
- Пользовательские теги (например, `#Фронтенд`, `#Нейросети`, `#Почитать`).
- Экспорт и импорт коллекции закладок в формате JSON.

### 6. ⚖️ Сравнение проектов (Repo Comparison)
- Наглядное сравнение двух репозиториев side-by-side (React vs Vue, Vite vs Webpack, FastAPI vs Flask и т.д.).
- Сравнительные диаграммы по звёздам, форкам, открытым багам и размеру кода.

### 7. ⚙️ Удобство и темы
- **Темы оформления**: GitHub Dark (Тёмная), Dimmed (Приглушенная) и Light (Светлая).
- **Языки интерфейса**: Русский и English.
- **Мониторинг лимитов API**: Индикатор оставшихся запросов к GitHub REST API.
- **Поддержка токена**: Возможность указать персональный токен GitHub (PAT) для увеличения лимита до 5000 запросов/час.

---

## 🛠️ Технологический стек

- **Frontend**: React 19, Vite, Tailwind CSS v4
- **Иконки**: Lucide React + кастомные Octicons SVG
- **Markdown & безопасность**: Marked.js + DOMPurify (XSS-защита)
- **API**: GitHub REST API v3 с интеллектуальным кэшированием и fallback-системой

---

## 🚀 Запуск и разработка

```bash
cd github-lite
npm install
npm run dev
```

Приложение доступно по адресу: `http://localhost:5173` (или в окне интерактивного предпросмотра).
